### 🚀 Proyectos Destacados

*   **App de Gestión de Inventario:** Aplicación en Android (Kotlin) con widgets de Glance en la pantalla de inicio, sincronizada con Google Sheets mediante Google Apps Script para el control de la despensa y la planificación de comidas.
*   **Plataforma de Nutrición Cross-Platform (En desarrollo):** Aplicación multiplataforma diseñada para conectar entrenadores y clientes con seguimiento de rutinas, calorías y autenticación integrada.
*   **Automatización de Citas Interactiva:** Script interactivo en HTML y AppleScript con diseño personalizado para agendar planes directamente en Google Calendar.
*   **Optimización de Sistemas y Seguridad:** Configuración de firmas de Secure Boot (sbctl) en entornos duales y despliegue de máquinas virtuales con Debian/Ubuntu y Docker.
